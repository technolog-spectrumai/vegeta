# vegeta-core

The Vegeta workbench: workspaces, designs, immutable revisions, branching, human labels and recorded
evaluations (FEA, CFD, printing) on top of the tools in `vegeta-cli`. Plain files, no database; nothing
runs automatically. See `../docs/core.md`.

```bash
pip install -e vegeta-cli -e vegeta-core
vegeta ws --help
vegeta rev --help
```
