# vegeta-fidia

Fidia (Italian for Phidias, the sculptor) is Vegeta's AI modelling: from a prompt to a checked, exported 3D
model through a bounded plan → generate → run → check → render → review → revise loop; the design copilot
(`DesignSession`) and bounded parameter campaigns (`Campaign`). The connection to the AI provider is
`vegeta-ai`. See `../docs/fidia.md`.
