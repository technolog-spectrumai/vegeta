# Marine lab — what floats and dives

Generated by `python tools/lab.py readme` from where the files are — run it again after moving things.

| folder | files | what |
|---|---:|---|
| `studies/` | 3 | the notebooks: a study per machine or part (stage 1) |
| `designs/` | 4 | the machine modules, imported by plain name (`import nisus_flight`), and `machines.py` (what this lab exports) |
| `sims/` | 0 | MuJoCo scenarios and their runners: the designs that graduated to simulation |
| `campaigns/` | 0 | data gathering and optimisation loops |
| `exp/` | 0 | limbo: speculative designs and their notebooks — nothing imports them (`tools/lab.py promote` when something should) |
| `common/` | 0 | this lab's snippets and tools |
| `tests/` | 2 | `python tools/lab.py test marine` (mocks) |

A notebook starts with::

    DEBUG = True
    from vegeta.labkit import bootstrap
    DEBUG = bootstrap.lab("marine", DEBUG)
