# Legged lab — what walks

Generated by `python tools/lab.py readme` from where the files are — run it again after moving things.

| folder | files | what |
|---|---:|---|
| `notebooks/` | 4 | the notebooks: one per machine or part (stage 1); notebook-only folders inside it (aero: `races/`) |
| `designs/` | 35 | the machine modules, imported by plain name (`import nisus_flight`), and `machines.py` (what this lab exports) |
| `sims/` | 1 | MuJoCo scenarios and their runners: the designs that graduated to simulation |
| `campaigns/` | 6 | data gathering and optimisation loops |
| `exp/` | 0 | limbo: speculative designs and their notebooks — nothing imports them (`tools/lab.py promote` when something should) |
| `common/` | 1 | this lab's snippets and tools |
| `tests/` | 9 | `python tools/lab.py test legged` (mocks) |

A notebook starts with::

    DEBUG = True
    from vegeta.labkit import bootstrap
    DEBUG = bootstrap.lab("legged", DEBUG)
